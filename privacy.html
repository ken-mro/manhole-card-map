プライバシーポリシー

制定日：2026年10月11日

マンホールカードマップ（以下「本サイト」）の運営者（以下「運営者」）は、本サイトの利用者の情報を次のとおり取り扱います。

1. 運営者が収集する情報

本サイトは静的なウェブページで、会員登録・問い合わせフォーム・アクセス解析ツール・広告はありません。運営者が利用者の個人情報を収集・保存することはありません。

2. 位置情報

  • 現在地の表示と、近いマンホールまでの距離の計算のために、ブラウザの位置情報機能を使います。利用には端末・ブラウザでの許可が必要で、許可しなくても地図は使えます。
  • 位置情報の処理はすべて利用者の端末内で行われ、運営者や第三者のサーバーに送信・保存されることはありません。ページを閉じると破棄されます。
  • 「Googleマップで経路を見る」を押した場合に限り、目的地（マンホールの位置）が Google に渡ります。その後の取り扱いは Google のプライバシーポリシーに従います。

3. 端末内に保存する情報

表示する弾の選択と、カードのデザインを表示するかどうかの設定を、次回も同じ状態で開けるよう、ブラウザの保存領域（localStorage）に保存します。この情報は利用者の端末内にだけあり、外部には送信されません。ブラウザのサイトデータを削除すると消去されます。Cookie は使用していません。

4. 外部サービスへの通信

本サイトを表示するために、ブラウザが次のサービスと直接通信します。その際、各サービスには IP アドレス、ブラウザの種類、閲覧した地図の範囲などの通信情報が送られることがあります。取り扱いは各サービスの方針に従います。

サービス用途
GitHub Pages（GitHub, Inc.）本サイトの配信。GitHub はセキュリティ目的でアクセス元 IP アドレスを記録します。
OpenStreetMap タイルサーバー地図画像の表示
GKP 下水道広報プラットホーム（gk-p.jp）マンホールカード画像の表示（デザイン表示をオフにすると、タップするまで読み込みません）
Google Fonts文字フォントの読み込み
cdnjs（Cloudflare）地図表示用プログラム（Leaflet）の読み込み

5. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から効力を生じます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の Issues からお寄せください。
