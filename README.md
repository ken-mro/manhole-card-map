# マンホールカードマップ

マンホールカードの題材になっているデザインマンホールの場所と現在地を地図に表示します。
カードを集めるためではなく、そのマンホールを見に行くことを楽しむためのサイトです。

https://ken-mro.github.io/manhole-card-map/

- 地図: Leaflet + OpenStreetMap
- カード情報・画像: GKP 下水道広報プラットホーム（https://www.gk-p.jp/）。本サイトは GKP・各自治体とは関係のない非公式サイトです。
- データ: `data.json`（2026-10-11 時点、第1〜29弾・東京都特別版）
